# 3. Уровни

## L1

- скорость целая км/ч, время целое число часов;
- без перевода единиц;
- `s = v × t` нацело, `s > 0`.

## L2 — типовая

- без обязательного перевода единиц;
- допускается «полчаса» / «полтора часа» при чётной скорости (итог целый км);
- либо целые часы с «типовым» диапазоном чисел шире L1.

## L3 — перевод единиц

- нужен перевод времени (мин → ч) **или** длины (м ↔ км) перед/после умножения;
- итог — целое число в спрашиваемых единицах.

## Взаимное исключение

| | L1 | L2 | L3 |
|---|---|---|---|
| перевод единиц | нет | нет | да |
| полчаса / 1,5 ч | нет | допускается | допускается вместе с переводом |

L4/L5: генератор **бросает ошибку**.

# 4. Подтипы и features

| subtype | Уровни | Смысл |
|---|---|---|
| `direct_hours` | L1 | целые км/ч и часы |
| `typical_hours` | L2 | типовой сюжет, без перевода |

| `time_convert` | L3 | минуты → часы |
| `length_convert` | L3 | м/км в ответе или данных |

`features`: `integer_hours`, `half_hour`, `needs_time_convert`, `needs_length_convert`, `answer_km`, `answer_m`.

# 5. generatorParams

```text
speedKmh, timeHoursExact, distanceKm, distanceAnswer, answerUnit,
subtype, features, seed, storyKind
```

Истина = независимый пересчёт `round(speedKmh * timeHoursExact)` в единицах ответа.

---

# 6. Дистракторы

L1/L2: `singleChoice` (4 варианта). L3: `numberAnswer`.

Модели: `v + t`; ответ скоростью `v`; забыл перевод; `v − t` / `t − v` если > 0; `v × t` в «сырых» минутах без деления на 60.

---

# 7. Seed и серия

`generateM30Series({ seed, countPerLevel })` — по 10 на L1/L2/L3; без `Math.random`; fingerprint = сюжет + числа.
