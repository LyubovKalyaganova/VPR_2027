# 2. Граница навыка

## Относительно соседей

| Сосед | Граница |
|---|---|
| M11 | время как промежуток — не скорость |
| M13 | длина/расстояние без «в час» — не M16 |
| M16 | единицы скорости и сравнение скоростей без сюжета движения |
| M30–M32 | «найди расстояние / время / скорость» в сюжете — **не** M16 |

## Что умеет ученик

- узнать запись вида `N км/ч` (или м/мин) как **скорость**;
- сравнить две скорости в одной единице;
- при необходимости сделать простой перевод соседних единиц, уместный в 4 классе (например, км/мин ↔ км/ч).

## Что НЕ относится к M16 (L1–L3)

- найти расстояние `s = v · t` (M30);
- полный сюжет движения;
- L4 стиль ВПР / L5 оценка «кто быстрее» без явных чисел единиц как отдельный формат.

# 3. Уровни

## L1 — узнать скорость

- выбор записи вида `N км/ч` среди не-скоростных единиц;
- выбор подходящей единицы скорости (км/ч);
- **без** trivia «величина N км/ч — это скорость»;
- без перевода единиц.

## L2 — сравнить две скорости

- две скорости в **одной** единице (км/ч);
- ответ — какая больше / на сколько (целое);
- без перевода между единицами.

## L3 — перевод + сравнение / разность

- **обязательно** `needs_convert` и разные единицы;
- структуры: км/мин↔км/ч, м/с↔км/ч;
- после перевода — сравнение или «на сколько»;
- **запрещено** писать в условии готовый перевод (`10 м/с = 36 км/ч` как подсказка);
- **запрещено** L3 = простое вычитание уже одинаковых км/ч.

## Взаимное исключение

| | L1 | L2 | L3 |
|---|---|---|---|
| узнать единицу | да | нет | нет |
| сравнение в одной единице | нет | да | допускается как часть |
| перевод / неудобные числа | нет | нет | да |

L4/L5: `generateM16Task` **бросает ошибку**.

# 4. Подтипы и features

| subtype | Уровни | Смысл |
|---|---|---|
| `recognize_speed_unit` | L1 | узнать км/ч как скорость |
| `compare_same_unit` | L2 | сравнить две скорости в км/ч |
| `compare_awkward` | L3 | неудобные числа / простой перевод |

`features`: `unit_km_h`, `unit_m_min`, `who_faster`, `how_much_faster`, `needs_convert`.

# 5. generatorParams

```text
subtype, features, seed
kind                  // 'recognize' | 'compare'
values                // числа скоростей
units                 // единицы
correctLabel          // строковый ответ при выборе
numericAnswer         // числовой ответ при numberAnswer / «на сколько»
```

# 6. Дистракторы

L1/L2: `singleChoice`, 4 варианта.  
L3: `singleChoice` или `numberAnswer` (при «на сколько»).

Модели: другая величина (длина/время/масса); соседняя скорость ±5/±10; ответ без перевода; перепутанные единицы.

---

# 7. Seed и серия

- `generateM16Series({ seed, countPerLevel })`;

# 8. Контрольные примеры

| Уровень | Пример | Почему уровень |
|---|---|---|
| L1 | «Какая запись означает скорость? 60 км/ч» | узнать величину |
| L1 | «60 км/ч — это …» → скорость | эталон |
| L2 | «Что больше: 55 км/ч или 48 км/ч?» | сравнение |
| L2 | «На сколько км/ч 70 больше 55?» | сравнение |
| L3 | «1 км/мин или 50 км/ч — что быстрее?» | перевод |
| L3 | «72 км/ч и 65 км/ч» | неудобные числа |

---

# 9. PROJECT_DECISION

1. `generatorId = gen.math.quantities.speed` (как черновик матрицы).
2. L1–L2 — преимущественно `singleChoice`; L3 — `singleChoice` / `numberAnswer`.
3. Простой перевод только км/мин ↔ км/ч (×60 / :60), без м/с.
4. Сюжеты «проехал … км за … ч» **не** генерируются (граница M30).

Карточка матрицы не менялась.
