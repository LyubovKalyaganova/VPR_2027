# Уровни

## L1 — два действия по порядку предложений
- Два явных шага подряд в тексте.
- Подтип: `two_ordered`.
- Примеры: купили A, потом ещё B, раздали C → сколько осталось.

## L2 — типовая двухшаговая
- Промежуточный результат скрыт.
- Подтип: `two_hidden`.
- Примеры: цена×кол-во, затем сдача; сумма двух покупок.

## L3 — три шага или лишние данные
- Подтипы: `three_steps`, `extra_data`.
- Примеры: три последовательных действия; двухшаговая с лишним числом.

# Дистракторы

Только первый шаг; сумма всех чисел текста; пропуск одного действия.
